# 金贝贝生图工具 JBBimg

一个开箱即用的本地 AI 生图工作台。JBBimg 将提示词、参考图片、生成参数、任务记录、项目分类和无限画布集中到同一个工作空间，并通过 OpenAI Compatible 图片接口完成文生图、参考图创作、提示词优化、组图规划与本地任务管理。

项目的核心工作界面采用单文件 HTML 组织，并封装为 Windows Electron 桌面应用。普通用户可以直接使用安装版或便携式免安装版，无需自行安装 Node.js 依赖或搭建开发环境。由于完整功能依赖桌面桥接提供本地存储、网络请求和文件访问能力，不建议直接双击源码中的 HTML 文件运行；需要修改源码的开发者请按照下文“从源代码运行”章节配置环境。

## 1. 项目解决什么问题

直接调用图片生成接口时，用户通常需要自行保存提示词、参考图和结果图片；任务较多后，还会遇到历史记录难以查找、失败任务难以重试、系列图片难以分类，以及实际返回尺寸与请求尺寸不一致却无法直观看出的情况。

JBBimg 主要解决以下问题：

- 将提示词、参考图、模型和尺寸等参数整理成可追踪的生成任务。
- 自动保留任务状态和生成结果，减少手工整理文件与重复复制提示词的工作。
- 使用项目、批次和无限画布组织多张图片及连续创作流程。
- 在任务卡片中记录请求尺寸、实际图片尺寸和比例，便于发现接口返回差异。
- 为失败、超时等任务提供状态反馈和重试入口。
- 将任务、项目、画布和接口设置保存在本机，不依赖额外的云端项目管理服务。

## 2. 主要功能

### 图片生成与编辑

- 支持纯提示词生图。
- 支持上传多张 PNG、JPEG 或 WebP 参考图进行图片编辑。
- 支持选择图片模型、尺寸、比例、输出格式和生成数量。
- 默认图片模型为 `gpt-image-2`，默认对话模型为 `gpt-4.1-mini`；可从已配置接口读取其支持的模型列表。
- 支持 PNG、JPEG 和 WebP 输出。
- 支持一次生成 1 至 10 张图片；兼容模式下会根据接口能力逐张发起请求。
- 支持 OpenAI 官方请求模式和 OpenAI Compatible 中转站模式。

### 提示词与批量任务

- 内置金贝贝助手，可补充、改写提示词并规划系列组图任务。
- 支持粘贴多条提示词，或导入 UTF-8、UTF-8 BOM、GB18030 编码的 TXT/MD 文件创建批量任务。
- 支持智能识别提示词条目，也可以按“每行一条”拆分任务。
- 支持从提示词中识别常见图片比例，并在提交前预览批次内容。

### 任务与项目管理

- 显示等待、生成中、成功、失败和超时等任务状态。
- 支持失败任务重试、批量重试、批量保存和批量删除。
- 支持新建、重命名、合并和删除项目。
- 多选任务后可移动到已有项目，或直接创建新项目归类。
- 支持任务堆叠展示和任务卡片尺寸调整。
- 根据图片文件本身读取实际分辨率和比例；当实际结果与请求不一致时，同时显示请求值与实际值。
- 支持按项目导出已生成图片。

### 无限画布与创作工具

- 无限画布支持提示词、参考图、生成器、任务和结果等节点。
- 节点名称可以双击重命名，节点连接关系可用于组织生成流程。
- 支持在画布中发起生成并显示任务状态和结果。
- 3D 视角工具可为人物或产品生成不同机位的拍摄约束。
- 4K 高清修复支持放大、分块处理、重叠羽化和接缝检测，也提供纯本地处理选项。
- 创作灵感页面用于浏览和整理公开来源的灵感素材。公开源码仓库不附带抓取到的第三方素材，用户可在程序中自行触发同步。

### 本地数据与界面

- 项目、任务、画布、接口配置和生成文件均保存在本机。
- 可自定义图片输出目录；切换目录时，程序会迁移已有的 `images` 和 `videos` 子目录内容。
- 支持从旧版 HTML 工具目录导入历史任务与图片，导入内容默认归入“旧版导入”项目。
- 旧版导入只复制历史数据，不会把旧版接口地址、API Key 或数据目录设为当前配置。
- 支持浅色、深色、跟随系统以及“金贝贝默认”“蕉绿”主题。
- 使用单实例运行机制，避免同时启动多个程序实例。

## 3. 安装方法

### 方法一：Windows 安装程序

1. 在 GitHub Releases 下载 `JBBimg-Setup-0.3.110-x64.exe`。
2. 双击安装程序，根据提示选择安装目录。
3. 安装完成后，从桌面快捷方式或开始菜单启动“金贝贝生图工具”。

当前安装程序未配置商业数字签名，Windows 可能显示“未知发布者”或 Microsoft Defender SmartScreen 提示。请确认安装包来自本项目的 GitHub Releases 后再继续安装。

安装新版本时可以覆盖原安装目录。卸载程序默认不会主动删除用户数据，但重要项目仍建议自行备份。

### 方法二：便携式免安装版本

1. 下载并完整解压 `JBBimg-0.3.110-portable.zip`。
2. 保持解压后的文件结构不变。
3. 双击目录中的 `JBBimg.exe` 启动程序。

不要只复制 `JBBimg.exe`，它需要与同目录下的 DLL、`locales` 和 `resources` 等文件共同运行。

### 从源代码运行

环境要求：

- Windows 10/11 x64
- Node.js `22.12.0` 或更高版本
- npm

## 4. 使用方法

### 首次配置

1. 启动 JBBimg，打开右上角的设置面板。
2. 在“连接”区域选择请求模式：
   - `中转站兼容`：用于 OpenAI Compatible 接口。
   - `OpenAI 官方`：用于 OpenAI 官方 Image API。
3. 填写中转站地址和生图 Key。部分第三方地址还需要单独填写文本 Key，供金贝贝助手使用。
4. 点击“读取模型”，验证连接并读取接口支持的模型。
5. 根据需要，在“本地保存”中选择自定义图片输出文件夹。

API Key 会写入本机应用数据目录中的 `.env` 文件，不应提交到 GitHub、截图公开或发送给他人。

### 创建单个任务

1. 在主界面输入提示词。
2. 如需参考图，点击附件按钮并选择 PNG、JPEG 或 WebP 图片。
3. 选择模型、尺寸、图片比例、输出格式和生成数量。
4. 点击生成按钮。
5. 在任务卡片中查看状态；生成成功后可打开大图、下载图片或查看请求与实际尺寸。
6. 如果任务失败或超时，可通过任务卡片或详情面板重新生成。

### 创建批量任务

1. 打开“批量生图”。
2. 粘贴多条提示词，或导入 TXT/MD 文件。
3. 选择“智能识别”或“每行一条”。
4. 检查识别预览、任务数量和图片比例。
5. 选择统一模型与比例后确认创建。

### 使用项目与无限画布

- 在项目区域新建项目，用于归类不同主题或客户的任务。
- 进入多选模式后，选择任务并使用“移动到”归入新项目或已有项目。
- 打开无限画布，添加提示词、参考图和生成器节点，连接后发起生成。
- 双击节点名称可以重命名；生成结果会作为结果节点保留在画布中。

### 导入旧版历史记录

1. 打开“设置 > 本地保存”。
2. 点击“导入旧版记录”。
3. 选择包含旧版 `data/tasks.json` 或 `outputs/output1` 图片目录的旧版工具根目录。
4. 程序会优先恢复带完整索引的任务；缺少索引的图片可在确认后按图片文件重建记录。

缺少原始索引的图片无法恢复原提示词和部分请求参数，程序会将其标记为“旧版文件恢复”。导入过程不会修改当前接口地址、API Key 或数据目录。

## 5. 输入输出示例

### 示例一：纯提示词生成

输入：

```text
提示词：清晨的社区共享花园，居民一起整理植物和工具，纪实摄影，自然光，画面干净，16:9
模型：gpt-image-2
请求尺寸：自动，根据提示词判断
输出格式：PNG
生成数量：1 张
参考图：无
```

可能得到的任务记录：

```text
状态：已完成
模型：gpt-image-2
请求比例：16:9
请求尺寸：由当前接口和自动尺寸策略决定
实际比例：根据返回图片文件读取
实际尺寸：例如 1536x1024
格式：PNG
```

实际尺寸由图片文件决定，可能与请求尺寸或比例不完全一致。JBBimg 会以读取到的实际宽高为准，并在不一致时同时显示请求值和实际值。

输出文件在安装版中的默认位置：

```text
%USERPROFILE%\Pictures\JBBimg\images\
```

用户可以在“设置 > 本地保存”中更改输出根目录。

### 示例二：参考图编辑

输入：

```text
提示词：保留参考图中的人物身份、服装和发型，将背景改为雨后的城市街道，半身构图，自然反光
参考图：portrait.png
模型：gpt-image-2
输出格式：WebP
生成数量：2 张
```

程序会通过图片编辑接口提交提示词和参考图，并为每张返回图片创建任务结果。是否能够严格保持人物或产品一致性，取决于所使用模型和接口的实际能力。

### 示例三：批量提示词

输入 TXT/MD 内容：

```text
1. 清晨社区广场，居民一起布置共享市集，16:9

2. 近景拍摄志愿者递出工具箱，4:5

3. 夜晚共享空间的交流活动，暖色室内灯光，3:4
```

识别结果：

```text
任务 1：比例 16:9
任务 2：比例 4:5
任务 3：比例 3:4
共创建 3 个独立任务
```

## 数据与隐私

安装版默认使用以下本地位置：

```text
应用数据：%APPDATA%\JBBimg\data\
运行日志：%APPDATA%\JBBimg\logs\
生成结果：%USERPROFILE%\Pictures\JBBimg\
```

其中可能包含 API Key、设置、任务、项目和画布记录。提交代码或反馈问题前，请勿上传以下内容：

- `.env`
- `settings.json`
- `tasks.json`
- `projects.json`
- `canvases.json`
- `logs/`
- 生成图片及包含私人内容的参考图

开发模式下，这些数据目录位于项目目录的 `data/`、`outputs/` 和 `logs/` 中。

当前主要面向 Windows x64 桌面环境。不同 OpenAI Compatible 服务对模型名称、参数、图片尺寸和返回格式的支持并不完全一致；遇到接口错误时，应同时检查模型名称、接口文档、额度、速率限制和中转站日志。
